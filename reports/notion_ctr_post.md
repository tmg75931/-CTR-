# 토스광고 클릭 예측(CTR) 모델 개발 정리

## 1. 문제 정의

토스 앱 광고 지면에서 사용자가 외부 디스플레이 광고를 클릭할 확률(CTR)을 예측하는 문제다. 광고 노출 1건마다 117개의 익명화 정형 피처와 사용자 행동 로그 시퀀스(`seq`)가 주어진다.

주최측 평가 지표는 순위 변별력(`AP`)과 클래스 균형 확률 오차(`50:50 WLL`)를 절반씩 합산한다. 원천 클릭률은 1.91%로 불균형이 크므로, 순위만 잘 맞추면 `WLL`에서 큰 손해를 본다.

```python
# 공식 결합 점수 산식
wll = 0.5 * (-np.mean(np.log(p[y == 1]))) + 0.5 * (-np.mean(np.log(1 - p[y == 0])))
score = 0.5 * average_precision_score(y, p) + 0.5 * (1.0 / (1.0 + wll))
```

## 2. 데이터와 환경

원천 학습 데이터는 1,070만 행(약 8.19 GB), 테스트 데이터는 153만 행(약 1.20 GB)이다. 로컬 PC 대신 Google Colab T4 GPU(VRAM 15 GB, RAM 12.67 GB, CPU 2코어) 환경에서 `google-colab-cli`로 노트북을 실행했다.

| 구분 | 항목 | 실측 수치 |
| :--- | :--- | :--- |
| 원천 Train | 행 수 / 컬럼 수 | 10,704,179행 / 119개 |
| 원천 Test | 행 수 / 컬럼 수 | 1,527,298행 / 119개 |
| 타겟 분포 | 클릭(1) / 미클릭(0) | 204,179건 / 10,500,000건 (CTR 1.9075%) |
| 요일 분포 | Train vs Test | Train 1~7 균등 / Test 100% 요일 7 (`TVD 0.8574`) |
| 용량 절감 | 원천 → 정형 Diet | 9.385 GB → 1.400 GB (85.09% 감소) |
| 모델링 Train | 1:5 층화 학습 세트 | 1,225,074행 (양성 100% + 음성 1:5, CTR 16.67%) |
| 모델링 Test | 추론 대상 | 1,527,298행 (원천 100% 전수) |

원천 용량의 84.4%(7,081.49 MB)를 `seq` 단일 컬럼이 차지했다. 12.67 GB RAM 제약을 넘기 위해 `seq`를 별도 Parquet으로 분리하고, 양성 클릭 전수(204,179건)와 요일별 층화 음성(1:5)을 묶은 공통 모델링 세트를 구성했다.

## 3. 접근

전체 파이프라인은 누수 차단과 메모리 절감을 우선 순위로 7단계 노트북으로 설계했다. 컴퓨팅 자원 한계로 1~5단계(전수 EDA, 경량화·CV, 시퀀스 요약, GBDT 4종 학습)까지 실행을 마쳤다.

1. **전수 EDA (`01`)**: 원천 분포와 결측 패턴을 모르고 전처리하면 누수와 왜곡이 생기므로 스트리밍으로 전체 스키마를 먼저 점검했다.
2. **데이터 다이어트 및 CV 고정 (`02`)**: 모든 모델이 같은 행과 같은 폴드에서 공정하게 비교되도록 정형·시퀀스 분리 및 `folds.parquet` 계약을 먼저 확정했다.
3. **시퀀스 요약 피처 추출 (`05`)**: 딥러닝 없이도 트리 모델이 `seq` 신호를 쓰도록 쉼표 구분 시퀀스에서 길이·고유 비율·최근 토큰 11종을 먼저 뽑았다.
4. **GBDT 베이스라인 (`03`)**: 파생 피처 효과를 측정할 기준선과 `50:50 WLL` 보정 전략을 먼저 확정했다.
5. **정형 FE 및 다중 GBDT (`04`)**: 117개 원천 피처를 244개(행 통계, 결측 비트마스크, 교호작용 해시, 폴드 격리 OOF 타겟 인코딩, `seq` 요약)로 확장해 LightGBM·CatBoost·XGBoost를 5-Fold로 학습했다.
6. **DeepCTR 및 이종 앙상블 (`06`, `07`)**: 코드 구현과 단위 테스트까지 마쳤으나 Colab 컴퓨팅 엔진 한계로 실행을 보류했다. `[확인 필요: DeepCTR OOF 점수, 최종 앙상블 점수]`

## 4. 핵심 판단

**시간축 검증 분리**: 테스트 데이터가 100% 단일 요일(`day_of_week = '7'`)로 구성된 점을 EDA에서 확인했다. 5-Fold Stratified CV를 기본 검증축으로 두되, 요일 7 슬라이스(`172,178`행)를 별도 OOT 지표로 함께 추적해 시간축 일반화를 점검했다.

**확률 보정 방식 선택**: 베이스라인 실험에서 무보정 확률은 `WLL 0.847438`로 점수가 크게 낮았다. `scale_pos_weight` 적용(`Score 0.515486`)보다 비가중 학습 후 Log-odds 공간에서 사전 확률을 0.5로 이동하는 `prior_shift`가 `AP` 손실 없이 `Score 0.517488`로 앞섰다.

**12.67 GB RAM OOM 해결**: XGBoost 5-Fold 학습 중 학습·검증·테스트 피처 행렬(약 7.34 GB)과 GPU DMatrix가 겹치며 커널이 종료됐다. 학습 단계에서 테스트 행렬 생성을 제거하고, 학습 완료 후 학습 프레임을 해제한 뒤 테스트 데이터를 25만 행 청크 단위로 변환·추론하도록 리팩터링해 OOM을 해결했다.

## 5. 결과

5-Fold OOF(1,225,074행)와 OOT 슬라이스(172,178행)에서 측정한 단일 모델 4종의 실측 성능이다.

| 순위 | 모델명 | 피처 수 | OOF AP | OOF 50:50 WLL | OOF Score | OOT Score |
| :---: | :--- | :---: | :---: | :---: | :---: | :---: |
| 1 | `xgb_fe_tuned` | 244개 | 0.415821 | 0.594157 | 0.521556 | 0.510586 |
| 2 | `lgbm_baseline` | 117개 | 0.409295 | 0.598260 | 0.517488 | 0.506630 |
| 3 | `lgbm_fe_tuned` | 244개 | 0.408997 | 0.599194 | 0.517156 | 0.505721 |
| 4 | `catboost_fe_tuned` | 244개 | 0.407804 | 0.596783 | 0.517032 | 0.504438 |

`xgb_fe_tuned`가 베이스라인 대비 OOF Score `+0.004068`, OOT Score `+0.003956` 상승하며 모든 지표에서 1위를 기록했다. 파생 피처군별 Gain 기여도는 원천 피처 45.04%, 행·이력 통계 31.39%, OOF 타겟 인코딩 21.02% 순이었다.

`seq` 요약 분석에서는 시퀀스가 짧을수록 클릭률이 높았다(`1~10` 토큰 29.72% vs `100+` 토큰 15.26%). 모델 간 OOF `raw_logit` 상관계수는 0.9641~0.9810으로 추후 블렌딩 여지가 남아 있다. `[확인 필요: 최종 리더보드 Public/Private 점수]`

## 6. 배운 점

10 GB대 실무 로그 데이터에서는 모델 구조보다 메모리와 입출력 설계가 병목이 된다. 처음부터 테스트 추론을 청크 스트리밍으로 분리했다면 OOM으로 날린 GPU 컴퓨팅 시간을 DeepCTR 학습에 쓸 수 있었다.

동일한 244개 피처에서도 LightGBM은 `scale_pos_weight` 적용 시 베이스라인(`prior_shift`)보다 점수가 소폭 하락한 반면, XGBoost는 큰 폭으로 상승했다. 다음 실험에서는 튜닝된 LightGBM·CatBoost에도 `prior_shift` 보정을 적용하고, 확보된 GPU 자원으로 `06` DeepCTR과 `07` 이종 앙상블을 이어서 검증할 계획이다.
